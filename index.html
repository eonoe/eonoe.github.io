// the workshop

Four live sessions. One real change shipped.

Two hours each, live and hands-on. You build alongside on a repo of your own and ask questions as you go. By the last session you have merged a change an agent wrote, and you know why it worked.

SESSION 1
Mon, Sep 21 · 6:00 PM

Get an agent doing real work

Install a coding agent and run a real session together, not a toy demo. Learn the loop every agent runs on: gather context, act, then verify, and put it to work on an actual task.

You leave with: an agent running on your own repo, doing something useful.
SESSION 2
Tue, Sep 22 · 6:00 PM

Context that makes it click

The difference between a vague agent and a sharp one is mostly context. Write your first AGENTS.md so the agent stops guessing and starts using your project's real conventions.

You leave with: an AGENTS.md the agent visibly follows.
SESSION 3
Wed, Sep 23 · 6:00 PM

Review like you mean it

The real skill is not prompting, it's reading what the agent wrote and pushing back. Review a change live, reject the part that's wrong, and merge the rest. This is the habit that keeps quality from sliding.

You leave with: your first agent-built change, reviewed and merged.
SESSION 4
Thu, Sep 24 · 6:00 PM

Make it stick

Turn a workflow you just did into something reusable, and learn when reaching for an agent is the wrong call. Then we open the floor: bring your repo and questions, and we work through them live.

You leave with: a reusable workflow, a sense of the limits, and your questions answered.

// faq

Questions, answered.

Is it really free?+
Yes. Your email is the only thing it costs. No card, no trial that quietly converts, no upsell wall in the middle.
Do I need to know how to code?+
Some. You should be comfortable in at least one language and able to find your way around the command line and Git. If you already write code, you're set.
Which coding agent do I need?+
Any current coding agent works. The habits transfer between them, so use the one you already have access to. Having access to one is the only hard requirement.
What if I miss a session?+
Every session is recorded. If you can't make one live, you'll get the recording, and you can still bring your questions to the next session.
How much time is it?+
Four live sessions of two hours each, eight hours total, across the launch week. Recordings are there if you need to catch up between sessions.
Does this lead into a paid course?+
It's the on-ramp. If 101 clicks for you, the deep AI Tech Lead track picks up where it leaves off and applies the same ideas to a real project. There's no pressure to continue, and 101 is built to be worth your time on its own.
